# FundsXML 4.2.9 — Documents Example

| **Schema version** | FundsXML 4.2.9 |
| **Validated against** | `https://github.com/fundsxml/schema/releases/download/4.2.9/FundsXML.xsd` |
| **Purpose** | Reference or embed fund documents |

## Contents

A copy of the realistic sample `../realistic/Fund-Documents_2025-10.xml` (generated by
`make_realistic.py`; fictional asset manager, funds and identifiers). `ControlData` and a
top-level `<Documents>` block for the *Example Multi Asset Opportunities Fund*, with three
`Document` entries:

| Type (ListedType) | Assigned to | Delivery |
|-------------------|-------------|----------|
| `Prospectus` | `Fund` by LEI | `DocumentURL` (link) |
| `PRIIPS-KID` | two share classes by ISIN | `BinaryData` (base64, embedded PDF) |
| `Factsheet` | one share class by ISIN | `BinaryData` (base64, embedded PDF) |

The embedded PDFs are one-page fictitious training samples; `SizeInBytes` equals the decoded
length. Required fields per document: `Type`, `Language`, `Format`.

## Validation

```bash
# Give the validator the schema (the official 4.2.9 release URL — or a local
# FundsXML.xsd path) + the XML file; the xmldsig sibling is handled for you:
XSD_Validation/cli/validate.sh \
        https://github.com/fundsxml/schema/releases/download/4.2.9/FundsXML.xsd \
        FundsXML_Files/4.2.9/documents/Fund_Documents.xml
```
